I’m excited to share a small but meaningful project I built using JavaScript — a number guessing game! 
This project challenged me to create a simple interactive experience where the player keeps guessing until they find the correct number. It involved:
- user input handling
- loop-based logic
- condition checks
- success feedback when the correct answer is reached
Building this game helped me strengthen my understanding of core JavaScript concepts such as variables, conditionals, loops, and user interaction. It was a fun way to practice problem-solving and turn logic into a playable experience.
Projects like this remind me that even the simplest ideas can become great learning opportunities in web development.
